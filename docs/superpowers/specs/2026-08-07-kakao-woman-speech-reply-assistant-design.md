# 카카오톡 여자어 답장 추천기 설계

- 작성일: 2026-08-07
- 상태: 사용자 승인 완료
- 대상: 개인용 모바일 반응형 웹앱 MVP

## 1. 제품 목적

사용자가 카카오톡 대화 전체를 업로드하면 대화방별 장기 맥락과 참여자별 특징을 분석한다. 사용자는 분석 결과를 직접 편집하거나 AI와 대화하며 교정할 수 있다. 이후 최근 대화와 현재 상황을 입력하면, 시스템은 장기 맥락과 현재 맥락을 결합해 한국 20대 여성의 카카오톡 말투를 콘셉트로 한 답장 세 개를 추천한다.

이 제품에서 `여자어`는 사용자가 명시적으로 선택한 핵심 콘셉트다. 특히 감정을 바로 단정해 말하기보다 관계와 상황을 고려해 간접적으로 드러내는 표현을 강조한다. 구현에서는 이를 재현 가능한 규칙, 예문, 관계 유형, 우회 강도로 구조화한다.

## 2. MVP 범위

### 포함

- 카카오톡에서 내보낸 `.txt` 파일 업로드
- 현재 대화 복사·붙여넣기
- 대화방별 장기 맥락 생성 및 저장
- 참여자별 관계, 말투, 행동 경향, 성격적 경향 분석
- 분석 근거와 확신도 표시
- 프로필 화면에서 항목별 직접 수정
- AI 교정 채팅을 통한 자연어 수정
- 사용자 수정 사항 잠금과 AI 변경 제안
- 친구 관계와 연인 관계 스타일 분리
- 여자어 우회 강도 1~5단계 설정
- 현재 대화에 한정한 강도 임시 변경
- 관련 과거 맥락 검색
- 같은 강도에서 전략이 다른 답장 세 개 추천
- 암호화 저장, 삭제 및 재분석

### 제외

- 카카오톡 앱 내부 직접 연동
- 다중 사용자 공개 서비스
- 결제, 구독, 관리자 화면
- 별도 여자어 모델 미세조정
- 사용자가 모르는 사이의 자동 발송
- 웹에서 발견한 사적 카톡 캡처의 무단 수집 또는 학습

## 3. 핵심 설계 원칙

1. 전체 대화는 장기 기억을 만드는 데 사용하고, 답장 생성 시에는 필요한 맥락만 검색한다.
2. AI의 성격 판단은 추정 정보로 표시하고 근거 및 확신도를 제공한다.
3. 사용자 확인과 수정은 AI 재분석보다 우선한다.
4. 현재 상황은 사용자가 직접 설명할 수 있으며 자동 추정 결과를 수정할 수 있다.
5. 여자어는 규칙과 허가된 실제 예문을 결합해 구현한다.
6. 친구 스타일에는 연애 뉘앙스를 억제하고, 여자친구 스타일에서만 애정·질투·관계 확인 신호를 허용한다.
7. 중요한 동의, 거절, 안전, 금전 및 약속은 높은 우회 강도에서도 핵심 뜻을 모호하게 만들지 않는다.
8. 카카오톡 원문은 최소 범위만 복호화하고 외부 AI 모델로 전달한다.

## 4. 사용자 흐름

1. 사용자가 개인 계정으로 로그인한다.
2. 카카오톡 `.txt` 파일을 업로드한다.
3. 시스템이 참여자를 추출하고 사용자에게 본인 이름을 확인받는다.
4. 시스템이 메시지를 파싱하고 장기 기억과 친구 프로필을 생성한다.
5. 사용자가 프로필 화면 또는 AI 교정 채팅에서 분석을 수정한다.
6. 사용자가 답장 생성 화면에서 최근 대화를 붙여넣는다.
7. 사용자가 현재 상황과 답장 목적을 입력하거나 자동 추정 결과를 확인한다.
8. 시스템이 관련 과거 맥락을 검색하고 여자어 답장 세 개를 생성한다.
9. 사용자가 답장을 복사하거나 수정한다.
10. 선택·수정·폐기 피드백은 사용자가 허용한 경우 개인화 규칙 개선에 사용한다.

모바일 핵심 화면은 `대화방 → 친구 프로필 검수 → 현재 상황 입력 → 답장 추천` 순서로 구성한다.

## 5. 시스템 구성요소

### 5.1 입력 및 파서

- 카카오톡 내보내기 형식을 검사한다.
- 대화방 이름, 날짜, 시간, 발신자와 메시지 본문을 표준 구조로 변환한다.
- 사진, 이모티콘, 삭제된 메시지처럼 본문이 없는 항목은 이벤트로 저장한다.
- 본문 없는 이벤트는 성격 판단의 강한 근거로 사용하지 않는다.
- 같은 방의 추가 업로드를 식별하고 중복 메시지를 제거한다.

### 5.2 대화 분할

두 단위를 구분한다.

- 메시지 턴: 한 참여자가 연속해서 보낸 메시지 묶음
- 대화 덩어리: 하나의 연속된 대화 세션

대화 덩어리는 30분 이상 중단, 날짜 변경, 명확한 주제 전환 또는 독립 사건 시작을 기준으로 나눈다. 시간 기준으로 먼저 분할하고 AI가 주제 경계를 보정한다.

각 대화 덩어리는 참여자, 시간 범위, 주제, 사건 유형, 요약, 감정, 관계 신호와 검색용 표현을 가진다.

### 5.3 계층형 장기 기억

장기 기억은 다음 계층으로 구성한다.

```text
원본 메시지
└─ 메시지 턴
   └─ 대화 덩어리
      └─ 사건·주제별 요약
         └─ 대화방 전체 요약
```

대화방 전체 요약에는 관계 구조, 전반적인 분위기, 반복되는 사건, 별명, 농담, 민감한 주제와 주요 변화를 저장한다.

### 5.4 친구 프로필

친구별 프로필은 다음 항목을 가진다.

- 사용자와의 관계 및 관계 유형
- 관찰된 성격적 경향
- 평소 말투와 자주 쓰는 표현
- 대화에서 맡는 역할
- 장난과 진지한 표현을 구분하는 단서
- 좋아하거나 불편해하는 대화 방식
- 관심사, 별명과 반복되는 사건
- 갈등 시 반응과 화해 방식
- 항목별 근거 대화
- 확신도와 마지막 확인일
- 출처: 사용자 확인, 사용자 수정, AI 추정 또는 AI 변경 제안
- 잠금 여부

사용자 확인 및 수정은 확정 정보로 취급한다. 새 대화가 잠긴 정보와 충돌하면 자동으로 덮어쓰지 않고 변경 제안을 만든다.

### 5.5 프로필 교정

사용자는 두 방식으로 분석을 교정할 수 있다.

1. 프로필 화면에서 항목별 직접 편집
2. `민수는 친한 사람에게만 저렇게 말해` 같은 자연어를 AI 교정 채팅에 입력

AI 교정 채팅은 사용자의 문장을 어떤 프로필 필드에 반영할지 먼저 보여주고 확인 후 저장한다. 조건부 특징은 단일 성격 단정이 아니라 적용 조건과 예외로 저장한다.

### 5.6 현재 맥락 분석

현재 맥락은 최근 20개 메시지 턴으로 시작한다. 다음 조건이면 `40 → 80 → 현재 대화 덩어리 전체`로 확장한다.

- 단답, 이모티콘, 웃음 표현의 비율이 높아 정보가 부족함
- 대명사나 생략된 대상이 불명확함
- 설명되지 않은 이전 사건을 언급함
- 감정 또는 답장 목적에 대한 해석이 여러 개임
- 관계 유형과 맞지 않는 표현이 감지됨

범위를 확장해도 해석이 불확실하면 사용자에게 구체적인 질문 하나를 한다. 사용자가 입력한 현재 상황 설명은 자동 추정보다 우선한다.

### 5.7 관련 과거 맥락 검색

검색은 다음 신호를 함께 사용한다.

- 같은 인물과 주제
- 유사한 갈등, 약속 또는 사건
- 반복되는 농담과 별명
- 과거에 효과가 있었던 화해 방식
- 상대가 불편해했던 표현
- 시간적 인접성과 현재 관계 상태

관련성이 높은 소수의 대화 덩어리와 요약만 생성 모델에 전달한다. 전체 원문을 매번 전달하지 않는다.

## 6. 여자어 스타일 엔진

### 6.1 스타일 기준

기준 스타일은 한국 20대 여성의 사적인 카카오톡 대화다. 기본 스타일은 여성 친구가 남성 친구에게 말하는 방식이며, 관계 프로필이 연인으로 확인된 경우에만 여자친구 스타일을 사용한다.

여자어 규칙은 한국어 성별어 연구, 국립국어원 메신저 말뭉치의 메타 변수, 허가받고 익명화된 실제 예시, 전문가 또는 사용자 검수를 거친 합성 예문을 조합해 개선한다. 특정 표현을 모든 여성에게 적용되는 사실로 취급하지 않는다. 제품 안에서는 사용자 선택형 스타일 규칙으로 다룬다.

참고 근거:

- 국립국어원 메신저 말뭉치는 성별뿐 아니라 연령, 관계, 친밀도 및 연락 빈도를 함께 기록한다.
- 2024년 메신저 말뭉치 연구에서는 `-음` 종결 사용이 성별뿐 아니라 연령, 친밀도 및 수평적 관계와 연관됐다.
- 한국어 구어 대화 연구에서는 여여 대화와 남남 대화에서 특징적으로 나타나는 종결어미 차이가 관찰됐다.

### 6.2 간접 감정 표현

스타일 엔진은 다음 순서로 감정을 변환한다.

1. 실제 감정을 서운함, 화남, 질투, 부담, 호감, 거절 또는 기대로 분류한다.
2. 관계 목표를 관계 유지, 사과 유도, 눈치 주기, 선 긋기, 관심 확인 또는 화해로 정한다.
3. 감정을 직접 단정하는 대신 상황 묘사, 질문, 완곡한 제안, 여운과 감정 단서를 조합한다.
4. 상대가 핵심 의도를 알아차릴 수 있는지 검사한다.
5. 중요한 의사결정은 모호하지 않게 보정한다.

사용 가능한 표현 장치에는 짧은 맞장구, 감정 리액션, 문장 분절, 웃음 표현, 모음 반복, 이모지, 완곡한 질문과 기대 행동 제안이 포함된다. 빈도는 관계, 현재 감정과 사용자의 개인 설정에 따라 달라진다.

### 6.3 우회 강도

- 1단계: 거의 직접적
- 2단계: 살짝 완곡함
- 3단계: 자연스럽게 돌려 말함; 기본값
- 4단계: 감정 단서를 은근하게 제시
- 5단계: 상당히 우회적으로 표현

사용자는 설정에서 기본 강도를 저장하고 답장 생성 화면에서 이번 요청에 한해 임시로 변경할 수 있다. 강도가 높아질수록 직접적인 감정 단어와 요구 표현은 줄고 상황 묘사, 여운, 질문, 완곡한 제안과 감정 단서는 늘어난다.

### 6.4 관계별 스타일

#### 여성 친구 스타일

- 친근함, 공감과 완곡함을 사용한다.
- 연애, 질투, 독점욕과 애정 확인 뉘앙스를 억제한다.
- 기존 남성 친구 대화의 농담과 관계 분위기를 유지한다.

#### 여자친구 스타일

- 애정 확인, 서운함, 질투와 관계 기대 신호를 허용한다.
- 관계 프로필이 연인으로 확인된 경우에만 적용한다.
- 관계 추정 확신도가 낮으면 사용자의 확인을 먼저 받는다.

### 6.5 답장 세 개

설정된 강도는 동일하게 유지하면서 전략이 다른 세 답장을 제공한다.

1. 관계를 부드럽게 유지하는 답장
2. 감정을 자연스럽게 눈치채게 하는 답장
3. 요구 또는 감정을 조금 더 분명히 전달하는 답장

각 답장은 한 줄짜리 전달 의도와 예상 위험을 가진다. 사용자는 복사하거나 수정 후 복사할 수 있다.

## 7. 저장 데이터

주요 데이터 단위는 다음과 같다.

- 계정 설정
- 대화방
- 참여자
- 원본 업로드 파일
- 정규화된 메시지
- 메시지 턴
- 대화 덩어리
- 사건·주제 요약
- 대화방 전체 요약
- 친구 프로필 항목
- 프로필 수정 및 변경 제안 이력
- 현재 맥락 요청
- 검색된 과거 맥락
- 생성된 답장과 사용자 피드백
- 여자어 스타일 규칙과 예문 버전

원본, 분석 결과와 사용자 수정 이력을 분리해 저장해 재분석 시 사용자 지식을 보존한다.

## 8. 보안과 개인정보

- 개인 계정만 접근할 수 있도록 인증한다.
- HTTPS로 전송 구간을 보호한다.
- 원본 파일, 메시지와 친구 프로필을 저장 시 암호화한다.
- 암호화 키와 데이터베이스 접근 권한을 분리한다.
- 외부 AI 모델에는 요청에 필요한 최소 범위만 전달한다.
- 친구 이름을 내부 가명으로 치환할 수 있다.
- 원문이 포함된 애플리케이션 및 오류 로그를 남기지 않는다.
- 원본 파일만 삭제, 분석 전체 삭제 및 계정 전체 삭제를 지원한다.
- 백업 데이터도 같은 암호화와 삭제 수명주기를 따른다.
- 외부 AI 처리 범위와 보존 정책을 사용자에게 표시한다.

서버와 외부 AI 모델이 분석 순간에 평문을 처리하므로 종단간 암호화라고 표시하지 않는다.

## 9. 오류 처리

- 지원하지 않는 파일 형식: 인식하지 못한 줄과 오류 위치를 미리 보여준다.
- 참여자 혼동: 장기 분석 전 본인과 주요 인물을 확인한다.
- 대용량 파일: 분석 작업을 단계별로 실행하고 진행률을 제공한다.
- 작업 중단: 완료된 단계부터 재개한다.
- 중복 업로드: 메시지 식별값으로 중복을 제거한다.
- 프로필 충돌: 자동 덮어쓰기 대신 변경 제안을 만든다.
- 맥락 부족: 범위를 확장한 뒤에도 부족하면 사용자에게 질문한다.
- 외부 AI 오류: 제한적으로 재시도하고 입력을 보존한다.
- 관계 오판 위험: 연애 표현 생성 전에 관계 프로필을 확인한다.
- 검색 결과 없음: 현재 맥락과 검수된 장기 요약만으로 생성하되 낮은 확신도를 표시한다.

## 10. 테스트와 평가

### 10.1 기능 테스트

- 여러 카카오톡 내보내기 형식을 파싱한다.
- 연속 메시지를 올바른 메시지 턴으로 묶는다.
- 시간과 주제 경계로 대화 덩어리를 나눈다.
- 재업로드 시 중복을 만들지 않는다.
- 사용자 수정과 잠금이 재분석 후에도 유지된다.
- 데이터 삭제 후 원문과 파생 데이터를 복구할 수 없다.

### 10.2 맥락 테스트

- 최근 20개 턴이 불충분할 때만 범위를 확장한다.
- 현재 사건과 관련된 과거 대화를 찾는다.
- 동명이인, 다른 대화방과 과거 사건을 혼동하지 않는다.
- 사용자가 제공한 현재 상황을 자동 추정보다 우선한다.

### 10.3 스타일 평가

- 감정 전달: 의도한 감정이 읽히는가
- 우회 강도: 1~5단계 차이가 일관적인가
- 관계 적합성: 친구와 연인 말투가 섞이지 않는가
- 자연스러움: 한국 20대의 사적 카톡 문장처럼 읽히는가
- 다양성: 세 답장이 단순한 어미 교체가 아닌가
- 명확성: 중요한 의사까지 위험하게 흐려지지 않는가
- 맥락 일치: 인물, 사건과 관계를 잘못 참조하지 않는가

초기 평가 세트는 일상, 약속, 갈등, 거절, 호감, 화해와 장난 상황을 포함한다. 공개 사용이 허용된 연구 자료, 동의받은 익명 예시와 검수된 합성 예문만 사용한다.

## 11. MVP 완료 기준

MVP는 다음 조건을 모두 충족할 때 완료로 본다.

1. 카카오톡 `.txt` 파일을 파싱하고 같은 방의 추가 업로드를 처리한다.
2. 대화방 장기 요약과 근거가 있는 친구 프로필을 생성한다.
3. 사용자가 직접 편집과 AI 교정 채팅 모두로 프로필을 수정한다.
4. 현재 대화, 상황 설명과 답장 목적을 입력한다.
5. 적응형 현재 맥락과 관련 과거 검색이 작동한다.
6. 설정된 여자어 강도로 전략이 다른 답장 세 개를 만든다.
7. 여성 친구와 여자친구 스타일을 분리한다.
8. 원본 및 분석 데이터 삭제와 재분석이 작동한다.
9. 준비된 평가 세트에서 인물, 관계와 사건을 잘못 섞지 않는다.
10. 원문이 로그에 남지 않고 저장 데이터가 암호화된다.
